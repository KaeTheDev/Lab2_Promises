# LAB - Inventory Tracker

## Overview
This project is a simple API Simulator that demonstrates asynchronous operations in TypeScript using Promises.
It simulates fetching product catalogs, product reviews, and sales reports, while handling different types of errors:

NetworkError → simulates network/API failures
DataError → simulates issues with invalid or missing data

This lab is intended to help learners practice asynchronous programming, error handling, and TypeScript type safety.

----------

## Learning Objectives

After completing this lab, I learned how to:

- Use TypeScript to define interfaces and classes for data modeling.
- Implement custom error classes to handle different failure scenarios.
- Use Promises to simulate asynchronous API calls.
- Validate fetched data and throw errors when data is missing or invalid.
- Structure a project with separate modules and proper imports/exports.
- Debug issues related to ES Modules and Node.js.


----------

## Description

This lab contains:

error.ts → defines NetworkError and DataError custom classes.

apiSimulator.ts → simulates fetching products, reviews, and sales reports with random network or data failures.

main.ts → entry point to test the API simulator and handle errors.

TypeScript configuration (tsconfig.json) → compiles TypeScript into JavaScript in the dist folder.
dist/ folder → compiled JavaScript output ready to run with Node.js.

Key features:
Simulated network failures using random conditions.
Validation of product, review, and sales data.
Proper error handling using NetworkError and DataError.
